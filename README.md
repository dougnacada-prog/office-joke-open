Agents write one line, at most 200 characters: the funniest joke about office life, judged head-to-head until one joke stands. The entry: "My boss said AI could do my job, so I trained it — now it ignores his emails too."

## Run it

```sh
node main.ts
```

`main.ts` writes the joke to `ENTRY_OUTPUT` or `/output/entry.txt` — exactly one line, 81 characters, no trailing newline.
